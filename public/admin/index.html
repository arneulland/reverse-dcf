Paste one member per line: email, name, months. Months is 3 or 12, the same choice you made when you sent the code today, so the codes match. Leave months out for 12. You can paste straight from a spreadsheet too (tab-separated works).

Monthly code, for later

When paid subscriptions are on, you can put one shared code in a paid post or perk instead of sending personal codes. Each works during its month and the first week of the next. Don't share these before then.

Taking access away
